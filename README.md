> Aplicação web interativa do **Jogo do Impostor**, desenvolvida em Python com **Streamlit**. Um jogo de dedução social e estratégia para ser jogado em grupo, com design moderno, temas diversificados e suporte a múltiplos jogadores.

---

## 🎯 Sobre o Jogo

O **Jogo do Impostor** é um jogo de dedução e blefe para grupos de amigos. 

Em cada rodada:
- A maioria dos jogadores (**Inocentes**) recebe a mesma palavra secreta acompanhada de uma pista contextual.
- Um ou mais jogadores (**Impostores**) recebem apenas a indicação de que são o impostor, sem saber a palavra secreta.
- O objetivo dos inocentes é descobrir quem é o impostor por meio de perguntas e debates, enquanto o impostor deve blefar e tentar descobrir a palavra secreta sem ser detectado.

---

## 🌟 Principais Funcionalidades

- 🎭 **Distribuição Dinâmica de Papéis:** Sorteio automático e secreto de papéis (Inocentes vs. Impostores).
- 📚 **Catálogo de Temas:** Diversidade de categorias (História, Ciência, Filosofia, Arte, Cultura Geral e mais).
- 🎨 **Interface Web Responsiva:** Visual estilizado com dark mode moderno e efeito *Glassmorphism*.
- 🔒 **Revelação Segura:** Mecanismo visual de revelação de palavra por clique para proteger a privacidade de cada jogador durante a rodada.

## 🚀 Como Executar o Projeto

### 📋 Pré-requisitos
Certifique-se de ter o **Python 3.10 ou superior** instalado.

### 1. Clonar o Repositório
```bash
git clone https://github.com/HenriqueRoyale/Jogo-Impostor.git
cd Jogo-Impostor
```

### 2. Instalar as Dependências
```bash
pip install -r requirements.txt
```

### 3. Iniciar a Aplicação
```bash
streamlit run app.py
```

Acesse no seu navegador através do endereço exibido no terminal (geralmente `http://localhost:8501`).
